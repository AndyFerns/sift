# Sift

**Find the clutter. Keep the code.**

Sift is an open-source, local-first tool that finds regeneratable development artifacts
(`target/`, `node_modules/`, `__pycache__/`, build directories and so on), tells you how much
disk they use, and helps you delete them safely.

This project is under active development. Full documentation lands with the first working
release; see [CHANGELOG.md](CHANGELOG.md) for what exists today.
